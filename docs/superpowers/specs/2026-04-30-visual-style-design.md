## Color Palette

Initial direction:

- Keep the palette restrained and content-first
- Preserve strong foreground/background contrast for long-form reading
- Extend the base theme conservatively before introducing more distinctive accents

## Typography

Initial direction:

- Prioritize comfortable article reading over expressive display typography
- Keep heading/body hierarchy clear and understated
- Any later type changes should preserve the lightweight, personal-blog feel established by `Astro Cactus`

## Layout Style

Initial direction:

- Use `Astro Cactus` as the structural baseline for page rhythm, article readability, and navigation density
- Prefer incremental layout tuning over full replacement in the first implementation phase
- Let bilingual navigation and category structure shape later layout adjustments

## Reference / Inspiration

- Current concrete reference: `Astro Cactus`
- Additional external style references can still be added later if a stronger personalized look is needed

## Dark/Light Mode

Initial direction:

- Reuse the theme's existing light/dark behavior where possible
- Only redesign mode styling if it conflicts with readability or the eventual visual identity
