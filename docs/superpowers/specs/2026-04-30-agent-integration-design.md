## Context

User is familiar with Claude/GPT API, tool use, RAG, multi-agent concepts. Wants something innovative, not generic chatbots or auto-translation.

## Ideas Explored (Not Selected)

- Living Blog — paragraph-level Q&A with RAG over all articles
- Knowledge Garden — AI-generated interactive knowledge graph
- Devil's Advocate — auto-generated counter-arguments for opinion posts
- Agent Playground — interactive Agent demos embedded in technical articles

## Requirements

- Must feel genuinely innovative, not "another AI chatbot"
- Should integrate naturally with the blog reading experience
- Backend will run on user's own server (separate from Vercel-hosted frontend)

## Current Decision

- No Agent feature is included in the initial blog implementation scope
- The blog frontend should remain structurally ready for future Astro Island based integrations
- New Agent ideas should be added here with timestamps as the blog direction becomes clearer

## Final Design

Deferred for a later implementation cycle. This document currently serves as the decision log and idea backlog for future Agent-enabled features.
