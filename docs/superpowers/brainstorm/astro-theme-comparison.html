选型建议

🏆 首选：AstroWind

5.6k stars，持续活跃，Astro v6 + Tailwind v4，功能最全面。高度可定制意味着你可以从这个基础出发，逐步逼近 Kimi 的视觉风格。适合"先搭框架再调设计"的开发路径。

  • 暗黑模式支持 system/light/dark 三种策略
  • 内置博客所需的全部基础功能（RSS、Sitemap、SEO）
  • Tailwind v4 的 CSS 变量体系方便后续做视觉定制

🥈 备选：Openblog

如果你更看重"开箱即用的博客体验"（目录、阅读时间、卡片网格、动画），Openblog 更接近 Kimi 的卡片风格，且内置 Tina CMS 方便内容管理。缺点是社区较小，遇到问题参考资料少。

  • 卡片网格布局最接近 Kimi 风格
  • 内置 Motion One 动画，页面过渡更丝滑
  • Tina CMS 提供可视化编辑能力

🎨 特别提及：Astro Ink

597 stars，最大特色是 6+ 内置色彩主题（cyan、purple、amber、green 等），通过 Tailwind 配置一键切换。使用 Svelte 构建交互组件。缺点是社区较小、Svelte 增加了技术栈复杂度。如果你对"多种预设色彩风格"感兴趣，值得一看。

  • 6+ 内置色彩主题，无需自己调色
  • Svelte 交互组件（主题切换器等）
  • Netlify CMS 集成，支持可视化编辑

💡 关于 i18n

五个主题都不内置 i18n，但 Astro 有官方 @astrojs/i18n 集成。无论选哪个主题，双语支持都需要手动配置路由和内容目录。这部分工作量与主题选择无关。
